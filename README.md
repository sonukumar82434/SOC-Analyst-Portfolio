# Password Spray Detection Lab

## Overview

This project demonstrates how to detect a Password Spray attack using Windows Security Logs, Sysmon, and Splunk Enterprise in a VirtualBox-based SOC home lab.

## Objectives

- Build a SOC Home Lab
- Configure Windows logging
- Install Sysmon
- Forward logs to Splunk
- Simulate a Password Spray attack
- Detect malicious activity
- Investigate the incident
- Map detections to MITRE ATT&CK

## Technologies

- VirtualBox
- Kali Linux
- Windows 11
- Sysmon
- Splunk Enterprise
- Python
- Sigma Rules
- Microsoft Sentinel
- Wazuh

## Skills Demonstrated

- SOC Monitoring
- Detection Engineering
- Incident Response
- Windows Event Analysis
- MITRE ATT&CK
- SIEM Investigation
